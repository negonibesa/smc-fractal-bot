У меня есть торговый бот на Python. Добавь в него новую стратегию входа.

**Логика стратегии "Центр бочонка":**

1. Бот определяет диапазон за последние N свечей (N = 20 по умолчанию):
   - range_high = максимум за N свечей
   - range_low = минимум за N свечей
   - equilibrium = (range_high + range_low) / 2

2. Бот проверяет, является ли текущая свеча бочонком или доджи:
   - body = abs(close - open)
   - range_ = high - low
   - body_ratio = body / range_ (если range_ > 0)
   - is_bochonok = body_ratio <= 0.4

3. Бот проверяет объём (Z-Score):
   - volume_mean = SMA(volume, 20)
   - volume_stdev = stdev(volume, 20)
   - z_score = (volume - volume_mean) / volume_stdev (если stdev > 0)
   - is_anomaly = z_score >= 2.0

4. Бот вычисляет центр бочонка:
   - bochonok_center = (high + low) / 2

5. Бот проверяет асимметрию относительно границ диапазона:
   - dist_to_high = range_high - bochonok_center
   - dist_to_low = bochonok_center - range_low
   - ratio = max(dist_to_high, dist_to_low) / min(dist_to_high, dist_to_low)
   - if 1.5 <= ratio <= 1.7: асимметрия подтверждена

6. **Условие входа:**
   - Если is_bochonok AND is_anomaly AND асимметрия 1.5-1.7:
     - Если bochonok_center ближе к range_low (dist_to_low < dist_to_high):
       → ЛОНГ (рынок пойдёт вверх к балансу)
     - Если bochonok_center ближе к range_high (dist_to_high < dist_to_low):
       → ШОРТ (рынок пойдёт вниз к балансу)

7. **Стоп-лосс:**
   - Для лонга: за range_low (или за фитиль бочонка)
   - Для шорта: за range_high (или за фитиль бочонка)

8. **Тейк-профит:**
   - Цель 1: equilibrium (центр диапазона)
   - Цель 2: противоположная граница (range_high для лонга, range_low для шорта)
   - Цель 3: 1.61 × bochonok_center (по твоей формуле)

9. **Фильтры (обязательно):**
   - Не входить чаще, чем раз в 4 часа
   - Не входить, если цена уже находится в середине диапазона (расстояние до обеих границ < 20% от всего диапазона)
   - Проверять старший ТФ (4H или D): если на старшем ТФ цена в середине — не входить

10. **Алерт:**
    - Отправлять уведомление в Telegram: "Сигнал: ЛОНГ/ШОРТ. Вход: X. Стоп: Y. ТП1: Z. ТП2: W. Z-Score: V. Ratio: R"

**Требования:**
- Код должен быть модульным (отдельная функция `check_bochonok_strategy()`)
- Все параметры (N, z_score_threshold, ratio_min, ratio_max) — в конфиге
- Логирование всех сигналов в файл
- Не ломать существующую логику бота

**Логика стратегии "Пересечение equilibrium":**

1. Бот определяет диапазон за последние N свечей (N = 20 по умолчанию):
   - range_high = максимум за N свечей
   - range_low = минимум за N свечей

   - is_anomaly = z_score >= 2.0

3. Бот проверяет, пересекает ли текущая свеча линию equilibrium:
   - prev_close = close предыдущей свечи
   - curr_close = close текущей свечи
   - crossed_up = prev_close < equilibrium AND curr_close > equilibrium
   - crossed_down = prev_close > equilibrium AND curr_close < equilibrium

4. **Условие входа:**
   - Если is_anomaly AND crossed_up:
     → ЛОНГ (цена пересекла equilibrium снизу вверх, идёт выравнивание)
   - Если is_anomaly AND crossed_down:
     → ШОРТ (цена пересекла equilibrium сверху вниз, идёт выравнивание)

5. **Стоп-лосс:**
   - Для лонга: за минимум текущей свечи (low) или за range_low
   - Для шорта: за максимум текущей свечи (high) или за range_high

6. **Тейк-профит:**
   - Цель 1: 0.5 × (equilibrium + range_high) для лонга (середина между equilibrium и границей)
   - Цель 2: range_high для лонга (противоположная граница)
   - Для шорта — зеркально

7. **Фильтры (обязательно):**
   - Не входить чаще, чем раз в 4 часа
   - Не входить, если цена уже пересекала equilibrium более 2 раз за последние 10 свечей (это шум)
   - Проверять старший ТФ: если на 4H/D цена в середине диапазона — не входить
   - Минимальный объём: z_score >= 2.0
