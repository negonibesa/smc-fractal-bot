# SMC Dashboard — Android APK

Тонкая обёртка над дашбордом бота (Flask, порт 80). Не отдельное приложение
с логикой: только WebView, который открывает `http://161.104.18.192`.

## Почему так, а не PWA

Service worker, а с ним и «устанавливаемость» в Chrome, требует secure
context — HTTPS или localhost. Дашборд живёт на голом IP по HTTP, поэтому
PWA не заработает в принципе, а не «плохо заработает». Отсюда APK.

## Сборка

Локально ничего не нужно: ни JDK, ни Android SDK на машине нет, и не надо.

1. Вкладка **Actions** → **Android APK** → **Run workflow**
2. Дождаться сборки, скачать артефакт `smc-dashboard-apk`
3. Передать `.apk` на телефон и открыть его (нужно разрешить установку из
   неизвестных источников для файлового менеджера)

Сборка запускается автоматически при пуше в `android-dashboard/`.

Локально, если всё-таки понадобится: JDK 17 + Android SDK, затем
`cd android-dashboard && gradle assembleRelease`.

## Установка и вход

При первом запуске спрашиваются три поля:

| Поле | Что вписать |
|------|-----------|
| Адрес | `http://161.104.18.192` |
| Пользователь | `DASH_USER` из docker-compose на VPS |
| Пароль | `DASH_PASS` оттуда же |

Значения сохраняются в приватном хранилище приложения. **В репозитории их
нет** — пароль дашборда в git не кладётся намеренно, см. раздел про
секреты в `CLAUDE.md`. Поменять: меню **Настройки** в правом верхнем углу.

Пароль лежит в `SharedPreferences` приложения без шифрования. Для внутреннего
APK, ставящегося вручную на своё устройство, это приемлемо; если приложение
попадёт на чужие телефоны — нужен `EncryptedSharedPreferences`.

## Две особенности этой установки

- **HTTP Basic.** Без `onReceivedHttpAuthRequest` WebView показывал бы
  браузерный запрос логина на каждом запуске. Перехват в `MainActivity`
  отдаёт логин и пароль автоматически.
- **Cleartext HTTP.** Android 9+ (API 28) режет открытый HTTP, и был бы
  белый экран без внятной причины. Разрешение вынесено в
  `res/xml/network_security_config.xml`. Если появится HTTPS (например,
  Cloudflare tunnel перед VPS) — файл и `android:usesCleartextTraffic`
  можно убрать.

## Подпись

Release подписан стандартным debug-ключом, поэтому APK ставится сразу и без
keystore. В Play Store так публиковать нельзя — только sideload.
